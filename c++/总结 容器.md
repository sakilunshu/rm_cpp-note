C++ 的容器（Containers）是 STL（标准模板库）中最核心的部分。你可以把它们理解为**“功能更强大、更安全的数组”**。

针对你这道题，我把容器操作分为**通用基础操作**和**针对本题的特定操作**来讲解。

---

### 一、 通用基础操作（几乎所有容器都有）

在使用任何容器前，记得包含对应的头文件（比如 `#include <vector>`，`#include <set>`）。

#### 1. 定义与初始化
```cpp
vector<int> v;          // 定义一个空的 int 类型 vector
set<int> s;             // 定义一个空的 int 类型 set
vector<int> v2(5, 0);   // 定义一个大小为 5，且初始值全为 0 的 vector
```

#### 2. 添加元素
*   **`vector` 和 `set` 都可以用 `insert()`**，但日常我们用得最多的是 `push_back()`（仅限 vector 等序列式容器）。
```cpp
v.push_back(10);  // 把 10 加到 vector 的末尾
s.insert(10);     // 把 10 插入 set（set 会自动排序并去重）
```

#### 3. 获取大小
```cpp
int size = v.size(); // 返回容器中元素的个数 (返回类型是 size_t，通常用 int 接收没问题)
if (v.empty()) { }   // 判断容器是否为空，为空返回 true
```

#### 4. 清空容器
```cpp
v.clear(); // 清空所有元素
s.clear();
```

---

### 二、 如何遍历容器（重点）

C++ 中有三种常见的遍历方式，前两种最常用：

#### 方式 1：传统下标遍历（仅限 `vector`）
`set` **不支持**这种写法，因为 `set` 内部是树结构，没有连续的内存地址，不能用 `s[0]` 访问。
```cpp
for (int i = 0; i < v.size(); i++) {
    cout << v[i] << " ";
}
```

#### 方式 2：C++11 范围 for 循环（推荐，最简洁）
适用于所有容器。
```cpp
// 意思是：对于 v 中的每一个元素，依次赋值给 x
for (int x : v) {
    cout << x << " ";
}

for (int x : s) {
    cout << x << " ";
}
```
*(注：如果容器里存的是复杂对象，想修改它，可以写成 `for (int &x : v)`)*

#### 方式 3：迭代器遍历（传统 STL 写法）
稍微繁琐，但在某些特定场景（如删除元素时）必须用。
```cpp
for (vector<int>::iterator it = v.begin(); it != v.end(); it++) {
    cout << *it << " "; // 注意：要用 *it 取值
}
```

### 三、 针对本题的特定高级操作

#### 1. 排序（`vector` 专属）
必须包含 `<algorithm>` 头文件。
```cpp
sort(v.begin(), v.end()); // 默认从小到大（升序）排序
// sort(v.begin(), v.end(), greater<int>()); // 如果想从大到小（降序）
```

#### 2. `set` 的初始化偷懒技巧
在你的题目中，要求将 `vector` 去重。你可以直接用 `vector` 的区间来初始化一个 `set`：
```cpp
// 把 v 从开头(begin) 到 结尾(end) 的所有元素，全部塞进 s 里
set<int> s(v.begin(), v.end()); 
```
因为 `set` 会自动去重和排序，所以此时 `s` 里面就是去重后的结果。

#### 3. 查找与删除（扩展知识）
*   **查找**：`s.find(10)`，如果找到了返回指向该元素的迭代器，找不到返回 `s.end()`。
*   **删除**：`v.pop_back()`（删除 vector 最后一个元素），`s.erase(10)`（删除 set 中值为 10 的元素）。

### 💡 避坑指南：`vector` 与 `set` 的核心区别

既然题目说“去重可使用 set 或自行实现”，你必须知道这两者的根本区别，这是考试常考的点：

| 特性 | `vector` (向量) | `set` (集合) |
| :--- | :--- | :--- |
| **底层结构** | 动态数组 | 红黑树（平衡二叉搜索树） |
| **元素顺序** | 按你插入的顺序存放 | **自动排序**（默认升序） |
| **元素唯一性** | 允许重复元素 | **不允许重复**（自动去重） |
| **访问方式** | 支持随机访问 `v[i]` | 不支持下标，只能用迭代器或范围 for |
| **查找效率** | 慢 \(O(N)\) | 快 \(O(\log N)\) |

**做这道题时的隐藏踩坑点：**
如果你用 `set` 去重，输出的时候要注意格式。因为 `set` 遍历输出时，本身就是有序且无重复的，所以其实你**不需要再对 `set` 进行 sort**。
