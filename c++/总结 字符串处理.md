这道题是一道非常经典的**字符串处理与容器应用**基础题。它虽然不难，但极其考验代码的基本功和细节处理。

帮你把这道题的“通关秘籍”总结如下，建议收藏，以后遇到类似的字符串/单词处理题可以直接套用：

### 🎯 一、 核心考点提炼
1.  **按行读取**：必须用 `getline(cin, str)`，绝不能用 `cin >> str`（因为后者遇到空格就停了）。
2.  **单词分割**：首选神器 `stringstream`（字符串流），它自带“跳过所有连续空格”的被动技能，极其好用。
3.  **数据存取**：学会使用 `vector<string>`（变长数组）或 `stack<string>`（栈）来暂存提取出来的单词。
4.  **格式控制**：逆序输出时，注意**最后一个单词后面不能有空格**（避免 Presentation Error 格式错误）。

---

### 🧠 二、 解题思路（最优解）
1.  **读入**：用 `getline` 读入一整句英文。
2.  **拆分**：把句子扔进 `stringstream ss(sentence)` 里。
3.  **提取**：写一个 `while (ss >> word)` 循环，把抠出来的干净单词依次 `push_back` 进 `vector` 数组里。
4.  **统计**：此时 `vector.size()` 就是单词个数。
5.  **倒排**：用一个 `for (int i = words.size() - 1; i >= 0; i--)` 循环，从后往前打印数组元素。

---

### 🪤 三、 极易踩坑的“Bug”点（你的血泪教训总结）
1.  **单复数不分**：`word`（单个单词）和 `words`（装单词的容器）千万别写混。`word.size()` 只是最后一个单词的长度，`words.size()` 才是单词总数。
2.  **忘记引入头文件**：用 `stringstream` 忘了 `#include <sstream>`，用 `vector` 忘了 `#include <vector>`。
3.  **把容器当字符串用**：`words[i]` 取出来的是一个完整的单词（如 `"Hello"`），千万不要在输出时再套一个循环去遍历它的字母（像你之前输出 `M` `R` 那样）。
4.  **多余空格**：逆序输出时，如果无脑在每个单词后面加空格，最后一个单词后面会多一个空格。要用 `if (i > 0) cout << " ";` 来控制。

---

### 💻 四、 标准代码模板（背下来！）
以后遇到“**统计单词数**”、“**反转句子中的单词**”、“**单词首字母大写**”等题目，直接默写这个模板：

```cpp
#include <iostream>
#include <string>
#include <sstream>
#include <vector>

using namespace std;

int main() {
    string sentence;
    getline(cin, sentence); // 1. 读整行
    
    stringstream ss(sentence);
    string word;
    vector<string> words; // 2. 准备容器
    
    while (ss >> word) {  // 3. 自动分割单词，跳过空格
        words.push_back(word);
    }
    
    // 4. 输出统计
    cout << "单词个数：" << words.size() << endl;
    
    // 5. 逆序输出 (核心逻辑)
    cout << "逆序输出：";
    for (int i = words.size() - 1; i >= 0; i--) {
        cout << words[i];
        if (i > 0) cout << " "; 
    }
    cout << endl;
    
    return 0;
}
```
