这是 The Cherno《Control Flow in C++ (continue, break, return)》的笔记整理。这一集紧接上一集的循环内容，重点在于区分三个控制流关键字各自的作用**范围**：`continue` 和 `break` 只影响循环，而 `return` 的影响范围是整个函数。

### `continue`：跳过本次循环的剩余部分

`continue` 的作用是立即结束当前这一次循环迭代，直接跳转到循环的“下一次迭代”准备阶段。

对于 `for` 循环，`continue` 会跳到迭代语句（如 `i++`），然后进行条件判断；对于 `while` 循环，则直接跳到条件判断处。一个典型用法是在循环中过滤掉不满足条件的元素，例如跳过偶数索引：
```cpp
for (int i = 0; i < 5; i++) {
    if (i % 2 == 0) continue; // i 为偶数时跳过
    std::cout << i << "\n";   // 只会打印 1, 3
}
```
需要注意的是，如果 `continue` 放在循环体的最末尾，它就没有任何实际效果，因为循环本来就要进入下一次迭代了。

### `break`：直接终止整个循环

`break` 的作用是**立即退出当前所在的循环**（或 `switch` 语句），程序继续执行循环之后的代码。它不关心循环条件是否仍然为真，一旦执行到 `break`，循环就彻底结束。

例如，在循环中寻找某个值，找到后就不必继续：
```cpp
for (int i = 0; i < 5; i++) {
    if (i > 2) break;         // i 为 3 时直接跳出
    std::cout << i << "\n";   // 打印 0, 1, 2
}
```

### `return`：退出整个函数

`return` 的作用范围最大，它会**立即结束当前所在的整个函数**，并将一个值（如果函数有返回类型）返回给调用者。

如果在 `main` 函数的循环中执行 `return 0;`，程序会直接终止，循环以及 `main` 中后续的所有代码都不会再执行。如果在一个普通函数内部的循环中使用 `return`，效果是跳出循环并跳出该函数，回到调用该函数的地方。

### 三者的关键区别

| 关键字 | 作用范围 | 效果 |
| :--- | :--- | :--- |
| `continue` | 仅限循环内部 | 跳过本次迭代，进入下一次 |
| `break` | 循环或 `switch` | 终止整个循环/分支，执行其后的代码 |
| `return` | 整个函数 | 结束函数，返回调用处 |

### 关键要点总结

- **`continue` 是“跳过这一个”**，`break` 是“不玩了”，`return` 是“整个函数到此为止”。
- `continue` 放在循环末尾等于没写。
- `break` 只跳出最内层的那一个循环（嵌套循环时需注意）。
- `return` 在 `main` 中会直接结束程序。
