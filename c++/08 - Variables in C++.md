这是 The Cherno《Variables in C++》的笔记整理。这一集的核心观点很明确：**C++ 中不同原始数据类型之间的唯一本质区别，就是它们占用的内存大小**。类型只是告诉编译器如何解释某块内存中的二进制数据。

### 变量的本质与核心观点

变量是给内存中某块数据起的名字，方便后续读写。Cherno 反复强调：`int`、`char`、`float` 这些原始类型之间，唯一的区别就是**大小（size）**，也就是创建变量时会分配多少字节的内存。数据类型的作用，是告诉编译器在读取这块内存时，应该按几位、如何解释。

### 常见数据类型与大小

以下大小以常见 64 位环境 / MSVC 为参考，实际可能因编译器而异：

| 类型 | 典型大小 | 说明 |
|------|---------|------|
| `char` | 1 字节 | 存储字符（本质是 ASCII 码数字） |
| `short` | 2 字节 | 短整型 |
| `int` | 4 字节 | 最常用的整型 |
| `long` | 4 或 8 字节 | 取决于编译器/平台 |
| `long long` | 8 字节 | 长整型 |
| `float` | 4 字节 | 单精度浮点数 |
| `double` | 8 字节 | 双精度浮点数 |
| `bool` | 1 字节 | 只有 true / false |

### 几个关键细节

**`char` 的双重身份**：`char` 既可以存字符，也可以存数字。`char a = 'A'` 和 `char a = 65` 在内存中完全一样，区别只在于用 `std::cout` 输出时，`char` 会被解释为字符，而其他整型会打印数字。

**`unsigned` 修饰符**：在整型前加 `unsigned` 会移除符号位，使该类型只能表示非负数，正数范围因此扩大一倍。例如 `int` 范围约为 -21 亿到 21 亿，而 `unsigned int` 范围约为 0 到 42 亿。

**浮点数的 `f` 后缀**：直接写 `float a = 5.5;` 时，`5.5` 默认是 `double` 类型，会被隐式转换。要明确声明 `float` 字面量，应写 `5.5f`。

**`bool` 为什么占 1 字节**：理论上 `bool` 只需 1 bit，但计算机**按字节寻址内存**，无法单独访问一个 bit，所以最小分配单位就是 1 字节。通常用 0 表示 `false`，非 0 表示 `true`。

**`sizeof` 操作符**：用于查看某个类型或变量占多少字节。注意它是操作符，不是函数，所以 `sizeof(int)` 和 `sizeof int` 都合法。

### 关键要点总结

- 变量是内存数据的命名容器，类型决定**分配多少字节**以及**如何解释这些字节**。
- 原始类型的大小由编译器/平台决定，`sizeof` 是验证大小的工具。
- `char` 存的是数字，输出时按字符解释；其他整型存字符字面量会输出数字。
- `unsigned` 去掉符号位，扩大正数范围。
- `float` 字面量必须加 `f`，否则默认是 `double`。
- `bool` 占 1 字节是因为内存按字节寻址，无法单独操作 1 bit。
