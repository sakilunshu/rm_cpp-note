这是 The Cherno《Constructors in C++》的笔记整理。这一集的核心是：**构造函数是一个在对象被创建时自动调用的特殊函数，专门用来初始化对象的数据**。C++ 不会像 Java 那样自动把基本类型成员清零，所以不写构造函数，成员变量里就是内存里残留的“垃圾值”。

### 为什么需要构造函数：C++ 不帮你初始化

先看一个没有构造函数的例子：
```cpp
class Entity {
public:
    float x, y;
    void Print() { std::cout << x << ", " << y << std::endl; }
};
```

如果你直接 `Entity e; e.Print();`，输出的是两个随机数。因为对象的内存分配了，但**没有被初始化**，里面是之前残留的值。如果直接在 `main` 里访问 `e.x`，编译器甚至会报“使用了未初始化的变量”。

### 笨办法：手动写一个 Init 函数

你可以加一个 `Init()` 方法，每次创建对象后手动调用：
```cpp
void Init() { x = 0.0f; y = 0.0f; }
// 使用：Entity e; e.Init();
```
这能解决问题，但缺点是**每次创建对象都得记得调一次**，代码啰嗦，而且容易忘。

### 构造函数：自动执行的初始化

构造函数解决了这个麻烦。它是一个**与类同名、没有返回值**的特殊函数，在你创建对象时**自动被调用**。

```cpp
class Entity {
public:
    float x, y;

    Entity() {          // 无参构造函数
        x = 0.0f;
        y = 0.0f;
    }
};
// 使用：Entity e;  // 自动调用 Entity()，x 和 y 被设为 0
```

现在创建 `Entity e;` 时，`x` 和 `y` 自动变成 `0, 0`，不需要再手动调 `Init()`。

### 带参数的构造函数（重载）

构造函数可以带参数，让你在创建对象时直接指定初始值。因为参数列表不同，这属于**函数重载**：

```cpp
Entity(float xa, float ya) {
    x = xa;
    y = ya;
}
// 使用：Entity e(3.0f, 10.0f);  // x=3, y=10
```

一个类可以有多个构造函数，只要参数不同即可。你既可以 `Entity e;`（用无参版本），也可以 `Entity e(3, 10);`（用有参版本）。

### 默认构造函数：编译器给的那个“空壳”

如果你**完全不写任何构造函数**，C++ 会为你生成一个默认构造函数，但它的函数体是**空的**，什么也不做。所以它不会帮你把 `x`、`y` 设成 0，这也是为什么必须自己写构造函数来初始化。

### 什么时候构造函数不会被调用

只有**实例化对象**时才会调用构造函数。如果你只是用类里的静态方法（`Entity::SomeStaticFunction()`），并不会创建对象，构造函数自然不会运行。

如果不想让外部创建这个类的对象，可以把构造函数设为 `private`，或者用 `Entity() = delete;` 显式删除它。

### 关键要点总结

- **构造函数在对象创建时自动调用**，用来初始化成员，名字与类名相同，无返回值。
- **C++ 不自动清零**，不写构造函数，成员里就是垃圾值，所以初始化是必须的。
- **可以重载**：无参版本给默认值，有参版本让调用者指定值。
- **默认构造函数是空壳**，不会帮你初始化任何东西。
- **只有创建对象才触发**，调用静态方法不触发；可以用 `private` 或 `= delete` 禁止外部实例化。
